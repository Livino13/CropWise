# CropWise

CropWise is a farmer-friendly crop recommendation and field planning app. It combines a machine-learning crop ranker with deterministic, field-specific growing plans, fertilizer stages, pest guidance, local weather, and a Gemini-powered assistant.

## Features

- **51-crop recommendation** using FCM clustering, PSO feature weighting, and a Random Forest classifier.
- **Crop Guide** with crop photos, in-season guidance, confidence bands, a soil-number glossary, and crop details on tap.
- **Field-specific plans** computed from soil values, field coordinates, weather, and available soil-test data.
- **Growing, fertilizer and pest guidance** with product grades and doses kept separate from AI narration.
- **Floating AI assistant** available across app pages. The Gemini key stays on the server.
- **Fields, recommendation history, feedback**, weather lookup, and optional AI explanations.
- **Crop photos for all 51 supported crops**, with an emoji fallback when an image is unavailable.

## Architecture

| Layer | Stack |
| --- | --- |
| Frontend | React 18, TypeScript, Vite, Tailwind CSS, Zustand, Leaflet |
| Backend | FastAPI, SQLAlchemy, Pydantic |
| Database | SQLite for local development; PostgreSQL supported |
| ML | FCM + PSO + Random Forest, 51 crop classes |
| External services | Open-Meteo weather, SoilGrids soil properties, Gemini via an OpenAI-compatible endpoint |

The ML model ranks crops. Growing, fertilizer and pest plans are computed by the local deterministic engine, not generated by an LLM. Gemini is used only for chat and optional plan narration.

## Quick start

### Backend

```powershell
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python train.py
python -m uvicorn app.main:app --reload
```

On macOS/Linux, use `source .venv/bin/activate` and `cp .env.example .env`.

The API runs at `http://127.0.0.1:8000`. Interactive docs are at `http://127.0.0.1:8000/docs`.

### Frontend

```powershell
cd frontend
npm install
npm run dev
```

The app runs at `http://localhost:5173`. Vite proxies `/api` to the local backend.

For a separately hosted frontend, set `VITE_API_URL` to the backend origin before building.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `LLM_API_KEY` | Server-side Gemini key. Chat is disabled when empty. |
| `LLM_MODEL` | Primary Gemini model name. |
| `LLM_FALLBACK_MODEL` | Fallback model used when the primary model is unavailable. |
| `LLM_BASE_URL` | OpenAI-compatible Gemini endpoint. |
| `DATABASE_URL` | SQLAlchemy database URL. Defaults to local SQLite. |
| `CORS_ORIGINS` | Comma-separated frontend origins allowed to call the API. |
| `SECRET_KEY` | Application secret. Change it outside local development. |

Never commit `backend/.env`. Use `backend/.env.example` as the template.

## API overview

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/health` | Health check |
| GET | `/api/meta` | App and pipeline metadata |
| POST | `/api/recommend` | Rank crops from soil and climate inputs |
| POST | `/api/plan` | Build a growing, fertilizer and pest plan for a crop |
| POST | `/api/chat` | Ask the Gemini assistant a question |
| POST | `/api/weather` | Look up climate averages for coordinates |
| GET/POST | `/api/fields` | List or create fields |
| GET/PUT/DELETE | `/api/fields/{id}` | Read, update or delete a field |
| GET/PATCH | `/api/history` | Read or update recommendation history |
| POST/GET | `/api/feedback` | Submit or read feedback |
| GET | `/api/analytics` | Legacy model analytics data |
| GET | `/api/status` | Model artifact status |
| POST | `/api/retrain` | Retrain the model |
| POST | `/api/guidance` | Legacy crop guidance endpoint |

## Model artifact

The trained model (`backend/app/ml/artifacts/model.joblib`, about 44 MB) is intentionally not committed to Git. Train it locally with:

```powershell
cd backend
python train.py
```

The Docker build also trains the model from `backend/data/crop_data.csv`.

## Docker

```powershell
$env:LLM_API_KEY="your-key-here"
docker compose up --build
```

- Frontend: `http://localhost:3000`
- Backend: `http://localhost:8000`

The frontend container proxies `/api` to the backend container. Set `LLM_API_KEY` in the environment to enable chat. If it is empty, the rest of the app still works and chat is disabled.

## Notes and limitations

- Sign-in is currently a local demo flow. Add real authentication before a public multi-user deployment.
- Fertilizer and pesticide grades and doses are guidance only. Confirm them with a local dealer or agriculture officer.
- Plan accuracy depends on the quality of soil values, field coordinates and weather data.
- Crop photo licensing should be reviewed before making the repository public.
- GitHub Pages cannot host the FastAPI backend. Use a separate backend host for a live deployment.
